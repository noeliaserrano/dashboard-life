# Mi agenda de plazos

Dashboard personal para organizar el día a día y no perder ningún plazo de la universidad (exámenes, prácticas, presentaciones), del trabajo y del TFG.

## Cómo usarlo

Abre `index.html` en el navegador. No necesita instalación ni servidor.

- Los datos se guardan en el propio navegador (localStorage).
- Usa **Exportar copia** de vez en cuando para guardar un `.json` de respaldo, e **Importar** para recuperarlo o pasarlo a otro ordenador.
- Se puede publicar gratis con GitHub Pages (Settings → Pages → rama `master`).
